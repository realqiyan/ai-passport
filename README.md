# AI Passport：语音输入

应用状态日期：2026-10-15；独立仓库迁移日期：2026-10-14。

目标：用设备麦克风和三个按键，在 Mac 上完成语音输入、编辑和回车。

## 获取完整项目

```bash
git clone --recurse-submodules https://github.com/realqiyan/ai-passport.git
cd ai-passport
```

已有克隆运行 `git submodule update --init source`。后续命令均从本仓库根目录执行，不依赖原工作区。`source/` 固定在官方基线 `33d3d1d93a1125b356b47b6d83a7a60121be801e`。Mac 安装见[语音应用](voice/README.md#mac-安装与更新)，构建见[开发手册](DEVELOPMENT.md)。

迁移保留 37 条项目提交、官方源码子模块和脱敏后的历史证据；范围、检查与旧 Mac 安装迁移见[迁移说明](MIGRATION.md)。

## 当前状态

- USB 与电池供电的 Wi-Fi 输入已实测出字。音频经 Mac 桥接送入 `Passport Mic`，由腾讯 Chatterfly 识别；按键由桥接注入。
- 三键固件与 Mac 桥接已于 2026-10-07 更新。麦克风默认关闭；上键短按开始／结束，确认键短按回车。完整按键表见[设备操作](voice/README.md#设备操作)。
- 维护源码已改为 `idle-v3`：关麦空闲 30 秒熄屏，5 分钟内保留 Wi-Fi 并使用自动浅睡，空闲满 5 分钟断网并按条件深睡。用户日志已确认此前 `idle-v3` 在设备运行并完成一次录音；本次将阈值从 15 分钟改为 5 分钟，已在 Mac 编译并刷入（归档 `5f2993a1…`），5 分钟边界待实机验收。
- 已实现后台电量采样、启动电压回退显示和唤醒时优先扫描上次信道。实现边界与验收步骤见[耗电排查](voice/POWER.md)；恢复延迟、自动浅睡比例和续航待实测。
- 本次源码已增加 `passport-voice` 默认 auto、USB 优先和断线回退，并区分停止信号、保存轮转日志；2026-10-11 已部署到 Mac 与设备，实测 USB 与 Wi-Fi 自动切换、录音和按键注入正常，运行无错误与异常停止。用户此前的异常退出来源仍待确认，见[停止排查](voice/README.md#异常停止排查2026-10-11)。
- 熄屏后按任意键只唤醒屏幕，不执行该键动作；唤醒的那次按键连同它随后的短按或长按一起被丢弃，需要再按一次才发送快捷键。2026-10-15 完整固件门禁通过（归档 `adb9c287…`）并已刷入设备，改动只在固件；熄屏按键行为待实机验收，见[设备操作](voice/README.md#设备操作)。
- 桥接可编辑安装已于 2026-10-15 改指本仓库（`pipx install --force -e ./voice/bridge`）；此前的安装指向旧工作区，运行日志不来自本仓库源码。
- 日常日志保留连接、录音和告警，并输出录音开始行、录音结束会话汇总与设备状态变化；`passport-voice --verbose` 可恢复详细诊断。终端和轮转文件同步降噪，每轮断线只提示一次，后续重试静默。2026-10-15 桥接检查 160 项通过，本次输出的设备实机验收待完成；说明见[桥接日志](voice/README.md#桥接日志)。

## 下一步

待机优化已于 2026-10-11 构建并更新桥接与固件：协商后每 5 秒心跳，关麦音频任务等待通知。USB 限时启动检查确认熄屏后改为 5 秒心跳且无周期误断线。下一步验证待机开麦、深睡恢复和耗电，见[待机优化实现](voice/POWER.md#待机优化实现2026-10-11已部署)。

1. 按[省电验收](voice/POWER.md#实机验收)继续验收 5 分钟边界、深睡唤醒和续航，并分段测唤醒到桥接 ready 的耗时。
2. 在设备上确认熄屏后第一次按键只亮屏，第二次才执行动作；同时观察深睡唤醒时按住按键是否执行动作，再决定是否调整。
3. 从已授权终端重启桥接，完成一次录音，确认新的桥接日志行。
4. 若再出现异常停止，用 `bridge.log` 末尾原因定位来源。
5. 修复 Mac 脚本测试中的 `/var` 与 `/private/var` 路径差异；当前记录不能视为脚本测试全部通过。
6. 自组设备先确认外形和按键，再选原型；移植及购买尚未执行。
