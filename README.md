# AI Passport：语音输入

状态日期：2026-10-11。

目标：用设备麦克风和三个按键，在 Mac 上完成语音输入、编辑和回车。

## 当前状态

- USB 与电池供电的 Wi-Fi 输入已实测出字。音频经 Mac 桥接送入 `Passport Mic`，由腾讯 Chatterfly 识别；按键由桥接注入。
- 三键固件与 Mac 桥接已于 2026-10-07 更新。麦克风默认关闭；上键短按开始／结束，确认键短按回车。完整按键表见[设备操作](voice/README.md#设备操作)。
- 维护源码已改为 `idle-v3`：关麦空闲 30 秒熄屏，15 分钟内保留 Wi-Fi 并使用自动浅睡，空闲满 15 分钟断网并按条件深睡。尚未构建或部署；上次部署记录仍为 `idle-v2`。
- 已实现后台电量采样、启动电压回退显示和唤醒时优先扫描上次信道。实现边界与验收步骤见[耗电排查](voice/POWER.md)；恢复延迟、自动浅睡比例和续航待实测。
- 部署与桥接检查已记录；Mac 脚本测试仍有路径断言失败，按键和省电待实机验收。完整结果只在[当前验收](voice/README.md#当前验收)维护。
- Linux 只维护源码、文档和不依赖设备的测试。构建、打包、桥接运行和设备验证在 Mac 完成，见[项目规则](AGENTS.md)。
